# 다른 컴퓨터에서 이어가기

이 저장소를 clone하거나 기존 저장소에서 pull한 후, Codex에서 이 폴더를 프로젝트로 열면 됩니다.

## 다른 로컬에서 실행하기

처음 받는 컴퓨터에서는 다음을 실행하세요.

```sh
git clone https://github.com/Jukyung-Choi/261106_teenieping.git
cd 261106_teenieping
python3 -m http.server 8080
```

이미 clone한 컴퓨터에서는 해당 저장소 폴더에서 최신 `main`을 받으세요.

```sh
git switch main
git pull --ff-only origin main
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080/menu-variant.html`을 엽니다. Codex에는 “README-continue.md를 읽고 이어서 작업해줘”라고 요청하면 됩니다.

- `DEMO → 0마리`: 미획득 안내 팝업 확인.
- `DEMO → 한 마리 늘리기`: 패널이 닫히고 소환 위치로 화면 이동 후 등장.
- 첫 접속 기본값은 10마리이며, 브라우저에 저장된 상태는 기기마다 별도입니다.

## 현재 작업 화면

- `menu-variant.html`: 최신 작업 화면. 이후 수정은 이 화면과 `menu-variant.css`, `menu-variant.js`를 기준으로 합니다.
- `redesign.html`: 이전 디자인 비교용 화면.
- `index.html`: 원본 게임. 기존 파일을 유지합니다.
- `assets/`: 캐릭터 WebP, 정지 이미지, Figma 팝업 및 배경 리소스. 모두 함께 필요합니다.
- `policy-engine.js`: 게임 정책 계산.

추가 패키지 설치 없이 HTML을 브라우저에서 열 수 있습니다. 로컬 서버가 필요하면 이 폴더에서 `python3 -m http.server 8080`을 실행하고 `http://localhost:8080/menu-variant.html`로 접속하세요.

- 처음 접속하는 기기의 기본 보유 티니핑은 10종입니다(`DEFAULT_OWNED_PING_COUNT=10`). 저장된 진행 상태는 그대로 복원하며, 데모의 ‘초기 상태로’도 10종을 복원합니다.

- 레전드 3종의 월드 FX를 EFFECT_1/2/3 참고 이미지의 흰 실루엣 테두리·뒤쪽 방사형 광선·선명한 별빛 조합으로 변경했습니다. 오로라핑은 핑크 중심(연보라를 줄이고 핑크빛 보강), 달콤핑은 골드·오렌지, 새콤핑은 라임·골드 후광입니다. 최신 요청에 따라 참고 이미지의 골드 톤을 다시 추가했습니다. 방사형 광선은 가로·세로 크기를 최초 적용 대비 약 31%(직전 대비 추가 약 16%) 줄였고, 후광·흰 테두리·별빛의 수는 유지했습니다. 별빛은 12개이며 몸 주변에만 따라다닙니다. Canvas·외부 이미지 라이브러리 없이 CSS 레이어로 구현했고 모션 줄이기 설정을 지원합니다.

- 새 티니핑 1마리 획득 시 랜덤 소환 위치로 화면을 400ms 동안 부드럽게 이동시킨 뒤, 도착하면 기존 80ms 팝 효과로 등장합니다. 이동 중에는 신규 캐릭터를 숨기고 유영·충돌에서 제외합니다. 첫 진입·여러 마리 소환·중복 획득에는 자동 화면 이동이 없습니다. 데모에서 ‘한 마리 늘리기’를 누르면 패널이 자동으로 닫힌 뒤 동일한 포커싱 연출을 확인할 수 있습니다. 직접 화면을 터치하면 자동 이동을 중단하며, 모션 줄이기 설정에서는 즉시 이동합니다. 소환 후 유영은 기존 방식을 유지합니다.

- 중앙 소환 기준 및 현재 화면 안에 배치하는 규칙은 제거했습니다. 보유 수와 카메라 위치에 관계없이 전체 월드의 플레이 범위에 랜덤 소환합니다. 첫 진입·보유 수 증가·뽑기에 적용합니다. 소환 간격은 25ms, 팝 효과는 투명도 변화 없이 80ms 동안 94% → 102% → 100% 크기로 거의 즉시 나타나도록 조정했습니다. 유영은 기존 월드 범위를 사용하며 중앙 복귀·화면 내부 제한은 없습니다.
- 30마리 밀집 시 유영을 방해하지 않도록 충돌 영역을 그림 크기의 90%로 조정하고, 충돌 영역 면적의 20% 겹침을 허용합니다. 분리 보정·반동을 약하게 했고, 충돌 때문에 유영 목표를 반복해서 덮어쓰지 않습니다. XP 소진 시 멈추는 기존 정책은 유지합니다.

- 개별 티니핑의 게이지·하트는 Figma `1172:60054`의 5분류로 통일했습니다. 핑크 `#ff4abd`, 블루 `#87d7ff`, 그린 `#93ec81`, 옐로 `#ffb53f`, 레드 `#fe6264`입니다. 각 캐릭터의 키컬러를 기준으로 분류하며, 보라 계열은 핑크로, 흰색 캐릭터는 의상·장식의 대표 색으로 분류합니다. 오로라핑도 핑크 계열로 통일합니다. 색상은 `PING_GAUGE_COLORS`, 캐릭터별 분류는 `PING_GAUGE_GROUPS`에서 수정합니다. 하트 원본 SVG는 `assets/gauge-colors-v3/`에 보관합니다.

- 레전드 3종의 광채 주변에 작은 별빛 12개가 3.6초 주기로 번갈아 반짝입니다. 캐릭터별 후광과 방사형 광선의 밝기·크기가 완만하게 변하며, 별빛은 캐릭터를 따라 움직입니다. 이동 경로에 남는 입자 효과는 없습니다. XP 소진 시 광선 회전과 별빛 애니메이션을 멈추고 밝기를 낮추며, 모션 줄이기 설정에서는 정적으로 표시합니다.

- 레전드 3종의 몸 위로 은은한 빛이 6.8초 간격으로 지나갑니다. 캐릭터 알파 마스크 안에서만 표현하며 3종의 위상을 2.2초씩 어긋나게 했습니다. XP 소진 및 모션 줄이기 설정에서는 꺼지고, 충전 연출 중에는 기존 충전 빛이 우선합니다. 몸 주변 광채와 몸 위를 지나는 빛의 강도를 한 단계 높였습니다(스윕 최대 불투명도 0.78, 흰 실루엣 테두리+캐릭터별 컬러 광채). 반복 간격은 유지하며, 이동 궤적의 반짝이 효과는 요청에 따라 제거했습니다.

- 도감 레전드·로열·일반 카드 배경: Figma `1210:42708`, `1210:42744`, `1210:42767` 적용. `assets/dex-card-v3/`의 원본 SVG를 사용하며 레전드는 테두리·내부·장식·별빛 5개 레이어로 구성합니다. 미획득 오버레이와 캐릭터·이름 배치는 유지합니다.
