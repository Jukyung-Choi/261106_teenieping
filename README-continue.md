## 실시간 색상 조절 및 최종 파일 제작 (2026-11-19)

- DEMO 06에서 슬라이더 또는 숫자로 채도 -100~+100, 입력 검정 0~254, 감마 0.10~3.00, 흰색 1~255를 조절합니다. 검정은 흰색보다 작게 유지합니다. ‘요청값 +25’는 +25 / 0, 1.00, 240으로, ‘보정값 초기화’는 0 / 0, 1.00, 255로 복원합니다.
- 전체 30종 유영·눈 감은 상태·도감에 원본 이미지와 SVG sRGB 필터를 사용합니다. UI·게이지·후광 색상과 충돌 영역은 바꾸지 않습니다. 비교창은 선택한 캐릭터의 원본과 보정을 나란히 보여줍니다. 전체 보정을 꺼도 오른쪽 비교는 현재 조절값을 표시합니다.
- 설정은 브라우저별 자동 저장됩니다. ‘설정 파일 저장’으로 JSON을 내려받아 최종 제작 시 전달하세요. 다른 기기로 브라우저 설정이 자동 이전되지는 않습니다.
- 미리보기와 아래 일괄 처리 도구는 같은 RGB 채도 행렬 + 입력 레벨 알고리즘(`srgb-matrix-levels-v1`)을 사용합니다. Photoshop HSL 채도 수치와 픽셀 단위로 동일한 결과를 보장하는 방식은 아닙니다. 이전 고정 미리보기의 HSL 방식 사본은 보관만 하며 최신 화면에서는 사용하지 않습니다.
- 최종 색감 확정 후에만 아래 도구를 실행합니다. Pillow와 NumPy가 필요합니다. 출력 폴더는 원본 assets와 별도 경로로 지정해야 합니다. 기존 출력 파일 덮어쓰기를 거부하며 원본은 수정하지 않습니다. 애니메이션 프레임·시간·반복·투명도를 검증하고 보고서를 저장합니다. WebP 재압축에 따른 미세한 차이는 최종 파일로 확인하세요. 기본 품질은 80이며 용량 상한을 자동 보장하지 않습니다.

