1. 사용자 확인으로 통일한 기준
- 화면 정책 8~9쪽 기준: Base XP 30%, Care XP 70%.
- 터치 1회당 min(15, 최대 XP - 현재 XP)만 회복.
- 충전분마다 생성 시각을 따로 저장하고 각 충전분은 즉시 선형 감소, 2시간 후 소멸.
- 새 터치나 전체 충전이 기존 충전분의 유효 시간을 연장하지 않음.
- 내부 리뷰 기획서 13쪽 기준: 하루 3회 무료, 4회부터 1젬.
- 상충하는 35/65 비율, 2시간 보호 후 시간당 4.5% 감소, 6시간 무료 쿨타임은 적용하지 않음.

2. 디자인을 유지하면서 적용한 기능
XP / 소울게이지
- 프레임마다 0.5%씩 차감하던 임시 규칙을 제거하고 시간 기반 계산으로 교체.
- 종별 최대 XP를 기준으로 실제 Current XP를 계산. 최소 XP는 해당 종 최대 XP의 30%.
- 헤더의 임시 숫자 999999를 보유 고유 티니핑의 실제 XP 합으로 교체.
- 게이지 바는 현재 합계 / 전체 30종 최대 XP 합계로 표시.
- 내부 계산은 소수점을 유지하고 표시 숫자만 반올림.
- 보상 단계 활성화는 반올림 전 XP로 판정.
- 50% 이하에서는 기존 떠다니는 모션의 속도와 폭을 줄임. 이미지·아이콘은 새로 만들지 않음.

전체 충전
- 충전 확인창의 기존 디자인 안에서 대상 수, 회복 XP, 필요 젬, 예상 소울게이지 안내.
- 보유한 티니핑만 충전하며 미보유 티니핑에는 XP를 지급하지 않음.
- 무료 3회 이후 1젬만 차감하고, 잔액 부족 시 충전하지 않음.
- 충전 대상이 없으면 무료 횟수·젬을 소비하지 않음.
- 확인 버튼을 반복 눌러 동일 팝업에서 중복 차감되는 상황 차단.
- 무료 횟수와 젬 잔액을 브라우저에 저장해 새로고침으로 초기화되지 않음.

보유 / 도감 / 배치
- 종별 고유 ID로 한 개체만 관리. 같은 종을 다시 획득해도 XP나 개체가 추가되지 않음.
- 도감의 보유 수와 미획득 상태를 실제 보유 데이터에 연결.
- 새 배치는 가상 셀과 랜덤 오프셋을 사용하고 초기 이름·게이지 중첩과 고정 메뉴 영역을 피함.
- 한 마리일 때는 중앙 부근 배치.
- 이미 저장한 티니핑 위치와 마지막 카메라 위치는 재진입 시 복원.
- 아래쪽 캐릭터가 앞에 보이도록 Y 좌표로 레이어 결정.
- 기존 이름과 XP 바는 모양·좌표를 유지한 채 캐릭터 이미지 위에서 표시.
- 캐릭터는 드래그로 이동하고, 빈 배경은 기존처럼 드래그로 이동.
- 캐릭터 드래그를 터치 회복으로 중복 처리하지 않음. 터치한 캐릭터는 앞으로 표시.
- 일반적인 몸체 겹침은 유지하고, 작은 캐릭터 면적의 70%를 초과하는 겹침만 제한.

랭킹 / 저장 / 팝업
- 내부 리뷰 기획서 29~31쪽에 따라 10분 단위의 실제 소울게이지를 누적.
- 백그라운드·재진입 시간도 계산에 반영하고 긴 미접속도 한 번에 계산.
- 현재 XP, 충전분별 시각, 누적 점수, 보유 상태, 위치, 무료 횟수, 보상 요청 이력을 저장.
- 팝업을 열면 배경 스크롤·캐릭터 드래그 차단, 닫으면 기존 위치 유지.
- 뒤로가기는 열린 팝업을 먼저 닫도록 처리.
- 도움말의 XP·충전 문구를 선택된 정책에 맞게 수정.
- 기존 DEMO 구성 유지. DEMO를 연 동안의 XP 일시정지는 테스트 편의 기능으로 유지.

3. 디자인이 필요해 변경하지 않은 항목
- 미획득 캐릭터의 잠금 아이콘·실루엣/명도 저하 표현.
  이전 사용자 요청대로 도감에서 30종의 실제 WebP 이미지는 계속 확인 가능.
- XP 50% 이하 전용 지친 표정과 주의 아이콘/바 표현.
  전달받은 WebP는 일반 대기 애니메이션이므로 별도 Tired/Happy/Drag 리소스가 필요.
- 미보유 시 강제 고정 안내 팝업, 다른 메뉴 비활성화, 뽑기 CTA의 새 디자인.
  현재 빈 화면 안내 문구만 기존 영역에서 유지.
- 받을 보상이 있을 때 띄우는 클릭 유도 말풍선/배지.
- 유료 배경 목록·구매·미리보기 화면, SNS 전용 진입/인증 화면.
- 이벤트 시작 전·집계 중·최종 확정 화면, 네트워크 오류·재시도 전용 화면.
기존 Figma 메뉴 위치, 소울게이지 외곽선, 폰트, 색상, WebP 표시 크기와 CSS 디자인은 바꾸지 않음.

4. 운영 확정 또는 서버 연동이 필요한 항목
- 이 결과물은 로컬 프로토타입. 서버·실제 ZEPETO 지갑·실제 리더보드와 연결되어 있지 않음.
- 브라우저 시간은 실제 운영의 신뢰 시간/부정행위 방지 수단이 아님.
  서버 시간, 충전 승인, 결제 원자성, 요청 ID, 실패 롤백, 보상 지급을 서버와 연결해야 함.
- 로컬 저장을 사용할 수 없는 환경에서는 재진입 저장이 제한됨.
- 랭킹 목록·순위는 기존 예시 데이터임을 표시. 내 누적 점수만 로컬 정책으로 계산.
  전 유저 최종 순위, 7단계 동점 정렬과 보상 대상 확정은 서버 데이터가 필요.
- 종별 Max XP 표는 문서에서 '예시'이며 실제 캐릭터와의 공식 매핑이 없음.
  기존 프로토타입의 30종 배정을 그대로 사용해 합계 8,060 XP로 계산. 최종 배정 확인 필요.
- 소울 보상 목록은 추가 사용자 확인에 따라 Figma 1140:40458의 6행을 적용.
  선물함 실제 지급을 했다고 표시하지 않고 로컬 수령 요청 기록으로 처리.
- 중복 획득에 대한 XP 미반영은 구현. 마일리지 지급액·컬렉템 이동/복귀와 실제 획득 동기화는 외부 시스템 연결 필요.
- 무료 횟수의 하루 기준은 현재 한국시간 00:00. 문서에 초기화 시간대가 없어 운영 확정 필요.
- 내부 문서의 2027-01-28~02-10 일정과 11월 운영 문구, 종료 후 계속 누적 방침과 종료 시 기능 정지 방침이 충돌.
  임의 일정이나 종료 처리를 적용하지 않음. 현재는 참여 가능한 프로토타입 상태 유지.
- SNS 기간·경품·해시태그, 배경 가격, 실제 이벤트 추적 ID는 확정 자료가 필요.
- 화면 정책의 가로 스크롤 미제공은 권장안이고, 사용자가 앞서 992×1586 상하좌우 이동을 명시했으므로 기존 월드를 유지.
  보유 수별 세로 길이 자동 확장은 적용하지 않음.

5. 검증
- 단위 검증: Base 하한, 터치당 15 XP/잔여량, 충전분별 만료, 이전 충전 시간 유지,
  중복 획득, 오프라인 10분 누적과 온라인 누적 일치, 무료 3회·유료 전환,
  잔액 부족, 무료 횟수 자정 초기화, 미보유 제외, DEMO 일시정지.
- 브라우저 검증: 실제 XP 합산, 도감 보유 수, 확인창 안내, 중복 차감 방지,
  새로고침 저장, 캐릭터 드래그와 터치 구분, 레이어, 70% 겹침 제한, 팝업 뒤로가기.
- 충전 확인창을 렌더링해 내용이 잘리지 않고 기존 디자인 안에서 표시되는지 확인.
