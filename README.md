# 티니핑 세상 WebView 프로토타입

Figma의 390×844 메인 화면을 기준으로 만든 의존성 없는 HTML/CSS/JavaScript 프로토타입입니다.

## 티니핑 월드

- Figma의 티니핑 10종과 개별 XP 게이지를 적용했습니다.
- 최초 실행과 데모 초기화 시에는 기본 5마리가 배치됩니다.
- 티니핑 이름 텍스트는 흰색 그림자 없이 검정 단색으로 표시됩니다.
- 캐릭터 영역은 세로로 스크롤되며 상단 게이지와 하단 메뉴는 고정됩니다.
- 각 행은 캐릭터 수와 관계없이 중앙부터 시작해 좌우로 확장되는 방식으로 배치됩니다.
- 모든 티니핑은 XP 100%에서 시작해 게임 실행 중 초당 0.5%p씩 독립적으로 감소합니다.
- 유영 이동 속도는 직전 설정보다 약 8% 낮춰 빠르지만 조금 더 부드럽게 조정했으며 상하 바운스 주기는 유지됩니다.
- 기본 상태에서는 유영과 별개로 캐릭터 이미지가 약 3~4px 범위에서 천천히 상하 바운스합니다.
- 정상적으로 유영 중인 티니핑은 서로 다른 주기로 한 번씩 위로 살짝 두 번 뛰며, 올라가는 순간에만 약 1.025배 커졌다 돌아오는 `콩콩` 바운스를 재생합니다.
- 배경, 상단 소울 게이지, 하단 메뉴 버튼은 Figma `99:18608`의 색상과 치수를 기준으로 다시 맞췄습니다.
- 랭킹 팝업은 `랭킹`과 `보상 안내` 탭으로 구성되며, 보상 안내에는 순위별 상위 랭커 보상만 표시됩니다.
- 랭킹 팝업의 탭과 나의 순위 카드는 고정되며, 그 사이의 랭킹 목록만 독립적으로 스크롤됩니다.
- 소울게이지 보상 팝업은 단계별 `받기` 버튼과 하단 고정 `한번에 받기` 버튼을 제공하며, 잠금·수령 완료 상태를 구분해 표시합니다.
- 상단 소울게이지 아래에는 나의 랭킹점수와 순위가 작게 표시되며, 데모 패널의 `점수·순위 표시` 토글로 노출 여부를 즉시 변경할 수 있습니다.
- 티니핑 또는 XP 영역을 터치하면 해당 티니핑만 XP 100%로 회복되고 전체 소울 게이지가 다시 계산됩니다.
- 터치 반응은 기울기 없이 캐릭터 전체가 250ms 동안 한 번 통 튀듯 확대·수축하는 빠른 스케일 펄스로 표현됩니다.
- XP가 30% 이하가 되면 값에 비례해 채도가 낮아지고, 회복 시 원래 컬러로 부드럽게 돌아옵니다.
- 캐릭터는 중앙 중심의 자유로운 높이와 간격으로 흩어져 배치됩니다.
- 각 티니핑은 기존 최고 속도를 유지하면서 더 넓은 가로·세로 반경에서 상하 바운스를 반복하며 유영합니다.
- 이동 목표는 위·아래·좌·우와 네 방향 대각선으로 구성된 8방향을 순환하며, 각도에 작은 편차를 더해 반복적으로 보이지 않게 합니다.
- 충돌 순간에는 스케일 변화 없이 좌우 방향으로 짧은 반동만 적용되고, 같은 두 티니핑의 연속 충돌에는 쿨다운이 적용됩니다.
- 충돌 박스는 실제 버튼 영역보다 작게 설정되어 캐릭터 외곽이 일부 겹칠 수 있으며, 중심부가 가까워졌을 때만 충돌로 처리됩니다.
- XP가 30% 이하가 되면 현재 위치에서 유영을 멈추고, 상하 바운스 폭은 정상 상태의 약 18%로 줄어 미세하게만 움직입니다. 약 3초 간격의 짧은 떨림도 유지되며, 터치로 회복하면 다시 정상적으로 유영합니다.
- XP가 30% 이하인 티니핑은 눈을 감은 상태로 유지되고, 회복하면 눈을 뜬 뒤 기존 깜빡임 모션으로 돌아갑니다.
- XP가 30% 이하에서는 채도가 더 빠르게 감소해 15% 부근부터 거의 흑백으로 보입니다. 개별 XP 트랙 배경은 `#340028`을 유지하고 채움 부분만 `#989898`로 전환됩니다.
- 화면 우측의 `DEMO` 버튼에서 전체 XP를 0~100%로 조절하고, 보유 마릿수를 0~30마리로 즉시 바꿀 수 있습니다. 15·20·25·30마리 프리셋은 등록된 10종을 반복 배치해 다수 캐릭터 환경을 테스트합니다.
- 티니핑 수와 관계없이 월드·스크롤 높이는 항상 `1180px`로 고정됩니다. 기본 배치의 충돌 판정은 `48×68px`, 다수 배치는 `42×60px` 중심 영역만 사용해 캐릭터 이미지가 깊게 겹친 뒤 튕깁니다.
- 데모 패널에는 슬라이더, 직접 입력, 빠른 프리셋, 마릿수 스테퍼와 초기화 기능이 있으며 패널을 연 동안 XP 자동 감소가 일시정지됩니다.
- 한번에 충전 완료 시 모든 티니핑이 동시에 살짝 커졌다 돌아오며, 빛과 7px 크기의 둥근 `★` 별빛이 넓게 퍼집니다. 별빛은 약 360ms 안에 빠르게 사라지고, 광택은 기존 캐릭터 PNG의 알파 실루엣 안쪽에서만 지나갑니다.
- 캐릭터별 좌안·우안의 중심 좌표와 크기, 눈꺼풀 색을 개별 보정한 오버레이가 서로 다른 주기로 짧게 나타나 눈 깜빡임을 표현합니다.
- 캐릭터끼리 닿으면 겹침을 해소하고 가볍게 튕겨 나갑니다.
- 데이터 배열에 캐릭터를 추가하면 월드 높이가 자동으로 늘어나 최대 30종 배치를 수용합니다.

## 실행

```bash
python3 -m http.server 8080 --directory outputs/teenieping-webview
```

브라우저에서 `http://localhost:8080`을 열면 됩니다.

## 인앱 브리지

뒤로 가기와 뽑기 이동은 연결된 환경에서 아래 브리지로 액션 JSON을 전달합니다.

- iOS: `window.webkit.messageHandlers.teenieping.postMessage(payload)`
- Android: `window.Android.postMessage(payload)`

페이로드 예시:

```json
{"type":"teenieping-action","action":"draw"}
```

지원 액션은 `back`, `draw`입니다. 나머지 메뉴는 현재 HTML 팝업으로 동작합니다.
